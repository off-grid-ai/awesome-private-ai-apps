## 1. Off Grid AI

**What it is.** An extension for Chrome and Firefox that pairs with Off Grid AI Desktop (OGAD) on the same computer. OGAD plans each task and drives a background tab in your own browser, signed in as you.

**Where the model runs.** On your computer, with the local model you pick in OGAD. The extension talks to OGAD at `127.0.0.1:7878`, or at a private-network address you set. If you pick a remote model in OGAD instead, the page text goes to that model. The websites still need the internet, and so does your first model download.

**What it refuses.** If the next step is a CAPTCHA or an "I'm not a robot" box, or would type into a password, one-time code, card number or CVV field, the task hands that step to you. The check lives in code, so it holds even when the model tries to go ahead.

**Best for.** You want the agent and the model on your own computer, in the browser you already use, Firefox included.

**Price.** Installing the extension is free and so is downloading OGAD. Chat and tasks from the extension need Off Grid AI Pro, at $34.99 once, a limited-time price down from $119, or $7.99 a month.

**The catch.** OGAD has to be running, and Edge, Brave and Arc are still on a waitlist. In Chrome you'll see Chrome's own "debugging this browser" bar while a task drives a tab. Pages that need visual control, such as canvas apps and maps, end the task and tell you why. The extension is young too, with version 0.0.6 shipped on 1 November 2026.

## 2. Nanobrowser

**What it is.** A free, open-source agent extension (Apache 2.0) for Chrome and Edge, per its [site](https://nanobrowser.ai/) and [GitHub](https://github.com/nanobrowser/nanobrowser). It works in your real, logged-in browser.

**Where the model runs.** Wherever you choose. You can use a cloud provider with your own API key, or a local model through Ollama, LM Studio or another OpenAI-compatible server.

**Best for.** You want a free agent you can point at a local model today, and you use Chrome or Edge. If you won't pay for Pro, this is the one to get.

**Price.** Free. You pay your model provider, or nothing if the model is local.

**The catch.** You set up and run the local model server yourself, and there's no Firefox version. Its README says the agent may not notice every step that needs your approval.

## 3. Claude in Chrome

**What it is.** Anthropic's Chrome extension. Per its [page](https://claude.com/chrome), it reads the page you're signed in to, then clicks, types and fills forms. It's generally available.

**Where the model runs.** On Anthropic's hosted Claude models.

**Best for.** Long, messy tasks, if you're fine sending your pages to Anthropic.

**Price.** Any paid plan. [Claude Pro](https://claude.com/pricing) is $20 a month, or $17 a month billed yearly.

**The catch.** It asks before purchases and actions you can't undo, but its page still tells you to keep it away from banking, health records and passwords, and says its prompt-injection protections "aren't foolproof".

## 4. ChatGPT browser extension (Codex)

**What it is.** OpenAI's extension, which you run from the ChatGPT desktop app. Per its [docs](https://learn.chatgpt.com/docs/chrome-extension), it reads or acts on sites where you're already signed in.

**Where the model runs.** On OpenAI's hosted models.

**Best for.** You already work in the ChatGPT or Codex desktop app and want the longest list of browsers.

**Price.** Not listed on the extension page.

**The catch.** It asks before each new website, and its "allow for all sites" option is marked elevated risk. The page doesn't cover payments, passwords or CAPTCHAs.

## 5. Gemini in Chrome

**What it is.** Gemini built into desktop Chrome, with an agent mode called auto browse that runs multi-step chores in your Chrome, per [Google's announcement](https://blog.google/products-and-platforms/products/chrome/gemini-3-auto-browse/).

**Where the model runs.** On Google's hosted Gemini 3.

**Best for.** You pay for Google AI and want an agent with nothing to install.

**Price.** Auto browse needs Google AI Pro or Ultra. Google's [plan page](https://one.google.com/about/ai-premium/) lists it for the US and India.

**The catch.** It pauses before purchases and social posts. With your permission it can sign in for you using Google Password Manager.

## 6. Browser MCP

**What it is.** A Chrome extension plus a local server that lets AI apps such as Claude Code, Cursor and Codex drive your browser profile, per [browsermcp.io](https://browsermcp.io/).

**Where the model runs.** In whichever MCP app you connect.

**Best for.** You're a developer and want your coding agent to reach pages you're signed in to.

**Price.** Not listed on its page.

**The catch.** You need Node.js 20 or later and an MCP app, and it lists no refusal for passwords, payments or CAPTCHAs.

## 7. BrowserOS

**What it is.** A free, open-source browser (AGPL-3.0) that agents drive with your logged-in accounts, per [browseros.com](https://www.browseros.com/).

**Where the model runs.** You bring your own AI provider keys and connect agents over MCP. Its site doesn't mention local models.

**Best for.** Running several agents at once, with replays of each session.

**The catch.** It's a second browser, so you sign in to your accounts again there. That rules it out if you want your own signed-in tabs.

**Is there an AI browser agent that works in my own signed-in Chrome tabs?**
Yes. Off Grid AI, Nanobrowser, Claude in Chrome, the ChatGPT browser extension, Gemini in Chrome and Browser MCP all work in the browser you're already signed in to. BrowserOS is a separate browser, so you sign in to your accounts again there.

**Which browser agent can use a model on my own computer?**
Off Grid AI runs the task model in Off Grid AI Desktop on your computer. Nanobrowser can use a local model through Ollama or LM Studio. Claude in Chrome, the ChatGPT extension and Gemini in Chrome use their makers' hosted models.

**Will a browser agent type my passwords or card numbers?**
Off Grid AI won't. Its task code hands the step to you when the target is a password, a one-time code, a card number or a CAPTCHA, even if the model tries to type it. Nanobrowser also hands payments, passwords and codes back to you.

**Does it work in Firefox?**
Off Grid AI's extension is on Firefox Add-ons and the Chrome Web Store. Nanobrowser lists Chrome and Edge. The ChatGPT extension lists Chrome, Edge, Brave, Opera and Vivaldi.

**Is Off Grid AI's browser extension free?**
