## How these lists are made

- Every price, platform and limit comes from the app's own website, store listing or GitHub page, fetched on the date shown.
- An app is left out when its last release is very old or a fact about it can't be checked.
- The lists are updated when prices or platforms change. If you spot a wrong fact, open an issue with a link to the source.
